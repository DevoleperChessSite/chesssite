# ChessSite

Шахматный веб-проект, предоставляющий интерактивную доску для игры, анализа партий и обучения.

## Описание
Проект представляет собой клиент-серверное веб-приложение для игры в шахматы в реальном времени. 
* **Клиент:** Реализован на чистом HTML, CSS и JavaScript (файл `index.html`). Обеспечивает отрисовку доски, логику перемещения фигур и пользовательский интерфейс.
* **Сервер:** (Предположительно) Обрабатывает игровые сессии, логику ходов, взаимодействие игроков и сохранение истории партий.

## Технологии
* **Frontend:** HTML5, CSS3, JavaScript (ES6+).
* **Анимация:** CSS-переходы для плавного перемещения фигур.
* **Backend:** (Уточнить в процессе разработки).

## Функциональность
- [x] Отрисовка шахматной доски (8x8).
- [x] Базовые правила ходов фигур (пешка, ладья, конь, слон, ферзь, король).
- [ ] Рокировка.
- [ ] Взятие на проходе.
- [ ] Превращение пешки.
- [ ] Шах и мат (детекция окончания игры).
- [ ] Таймер (часы).
- [ ] Сохранение и загрузка партий (FEN/PGN).
- [ ] Сетевая игра (WebSocket).
